## 왜 남기나

**결과만 보면 판단이 안 보인다.** 어떤 것을 왜 그 순서로 정했는지, 무엇을 금지했는지가
여기 있다. 각 step은 같은 꼴이다 — 「읽어야 할 파일 → 작업 → **금지사항** → 완료 조건」.

특히 **금지사항**이 판단의 기록이다. 예: `evidence_grade`를 점수 계산에 쓰지 마라 ·
직군·스킬 이름을 타입 안에 넣지 마라 · G2를 유사도 비교로 구현하지 마라.

## 이 사양과 실제 코드가 얼마나 맞나

사양이 언급한 경로 **77개 중 68개가 실제로 그 자리에 있다.** 나머지 9개는 아래.

**사양이 앞서 있는 것 — 계획했고 안 만든 것**

| 사양의 경로 | 무엇 | 실제 |
|---|---|---|
| `src/matching/pipeline/ledger.py` | 판단유탈 대장 (이력서의 모든 주장을 채택/배척/무관으로 분류) | **미구현.** `config.py`에 설정값만 남았다. **검산 G6이 이것에 의존하므로 G6도 안 돈다** |
| `src/matching/judge/ablation.py` | 소거 재채점 (항목을 빼고 다시 채점해 기여도 측정) | **미구현.** 설정값만 |
| `docs/DEMO.md` · `docs/OPERATIONS.md` | step13 산출물 | **미작성.** step13까지 못 갔다 |
| `data/.saramin_quota.json` | API 호출 기록 | **없다.** 키가 반려돼 호출 자체를 못 했다 |

**결과적으로 도는 검산은 G6을 뺀 6개다** — G1~G5(`src/matching/model/governance.py`) + G7(승인 무효화).

**사양이 뒤처져 있는 것 — 실행이 뒤집은 것**

| 사양 | 실제 | 이유 |
|---|---|---|
| `parser/vision.py` (이미지를 LLM에) | **폐기** | 비전 모델이 좌표를 지어낸다. 좌표가 근거 사슬의 끝이라 지어낸 좌표는 근거가 아니다 |
| step12 「배점 내림차순 그리디」 | **여유분 내림차순** | 배점이 커도 이미 만점이면 올릴 여지가 없다. 바꾼 사실을 `pipeline/contrast.py` 첫머리에 적었다 |
| UI는 범위 밖 | **업로드까지 구현** | 평가자가 자기 공고로 못 돌리면 「직군 무관」이 주장으로만 남는다 |

**어긋난 곳을 맞추려고 사양을 고쳐 쓰지 않았다.** 지시서는 그때 쓴 그대로 두고,
바뀐 것은 `docs/ADR.md`에 「개정」으로, 여기에는 표로 적는다.
